Sign in with a GitHub token that can write to your portfolio repository. Every change you publish becomes a commit, and GitHub Pages redeploys the site within about a minute.

How do I create the token?
  1. Open GitHub → Fine-grained tokens.
  2. Repository access: Only select repositories → your portfolio repo.
  3. Permissions → Repository → Contents: Read and write (and Pages: Read for deploy status).
  4. Generate, copy, paste above. It stays in this browser only.
